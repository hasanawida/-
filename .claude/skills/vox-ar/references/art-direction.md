# Art Direction — كيف تختار الشكل والموسيقى والراوي حسب الموضوع

الهدف: مونتاج "عصري" ومناسب للموضوع، مش قالب واحد يتكرر. القرارات الأربعة الأولى تُتخذ **قبل** كتابة البيتات وتُكتب في جذر `beats.json`.

## 1) الثيم `theme`
| الموضوع | الثيم | الخلفيات `bg` الشائعة |
|---|---|---|
| تحقيق، تاريخ، فضيحة، "الحقيقة وراء…" | `arabic-newsprint` | cream + red للصدمة، black للشتاء/الأزمة |
| علم، صحة، تربية، شرح مفهوم | `modern-editorial` | white + yellow للحقائق، red للتحذير |
| جريمة، مؤامرة، سرّ، "ملف" | `dark-investigative` | black + red، yellow نادر للتأكيد |
| تقنية، هندسة، "كيف يعمل" | `blueprint` | graph + yellow لليبلات |
| نوستالجيا، ثقافة شعبية، حكايات | `retro-magazine` | cream + مخطط بألوان الخردل |

## 2) مزاج الموسيقى `music.mood`
`investigative` (افتراضي للتحقيقات) · `tense` (خطر/أزمة) · `hopeful` (حلول/نهاية إيجابية) · `upbeat` (نصائح سريعة، ريلز)
· `epic` (تاريخ كبير/انتقالات) · `calm` (شرح هادئ/طبي) · `tech` (تقنية) · `kids` (تربية/أطفال).
فيلم 3 دقايق ممكن يبدّل المزاج مرة وحدة كحد أقصى (مثلاً investigative → hopeful عند الحل). للتبديل: بيتان في مشروعين ودمجهما، أو مزاج واحد.
موسيقى حقيقية مجانية: `"path": "jamendo"` مع `JAMENDO_CLIENT_ID` (اذكر الاعتماد من `audio/music_credits.txt`).

## 3) الراوي `tts.persona`
| الجمهور/النبرة | persona |
|---|---|
| وثائقي جاد (تاريخ/تحقيق) | `documentary_male` أو `gemini_narrator` |
| أهل وتربية، دفء | `documentary_female` أو `levant_female` أو `gemini_warm` |
| ريلز سريعة | `energetic` أو `gemini_energetic` |
| شرح تعليمي | `calm_teacher` |
| لهجة شامية قريبة (فلسطين/الأردن) | `levant_male` |

## 4) الصيغة والإيقاع
- ريلز/تيك توك: `9:16`، 30–60 ث، لقطة كل 3–4 ث، `energetic`/`upbeat`.
- يوتيوب: `16:9`، 3–8 دقايق، لقطة كل 4–6 ث، مزاج ثابت.

## اختيار القالب لكل لقطة (`preset`)
| ماذا يقول التعليق؟ | القالب |
|---|---|
| شخص/شيء واحد هو البطل | `hero_right` / `hero_left` (تبادل بينهما لتنويع الحركة) |
| رقم/إحصائية صادمة | `number` مع `value` (عدّاد) أو `stats` (مقارنة أرقام) |
| قائمة أعراض/خطوات | `checklist` (مع ✓/✗) أو `list` |
| مقارنة بين خيارين | `versus` |
| تسلسل زمني | `timeline` |
| شرح أجزاء صورة | `callouts` |
| نصيحة قصيرة/تذكير | `note` (ورقة لاصقة) |
| اقتباس | `quote` |
| انتقال/عنوان فصل | `title` (خلفية red/black) |
لا تكرر نفس القالب في لقطتين متتاليتين. نوّع `camera` (push_in / pan / pull_out / drift / static).

## قواعد "العصري"
1. لقطة = فكرة. عنوان واحد كبير + عنصر واحد + علامة واحدة (دائرة/سهم/ختم). أكثر من هيك = ضجيج.
2. الألوان: أصفر للحقيقة، أحمر للصدمة/التحذير، أبيض للسياق، أسود للتأكيد. لا أكثر من لونين للبارات في لقطة.
3. الحركة: كل شيء يدخل بترتيب القراءة (يمين→يسار)، حدث كل ~ثانية، لا أكثر من 6 طبقات.
4. الـ parallax افتراضياً 1.0 مع اللوحات الذكية (AI)؛ للوحات الجرايد الإجرائية الحركة على العناصر فقط.
5. الكابشن 4–5 كلمات، بار أبيض، الشريط السفلي محجوز له.
6. الأرقام دائماً أرقام لاتينية (2022، 100)، الاختصارات بالإنجليزية إذا كانت أشهر (AI, GPT).
7. تحويلات المشاعر: عند الانتقال من مشكلة لحل غيّر `bg` (من red/black إلى cream/white) و`headline_bar` (من red إلى yellow).

## الصور الذكية (`plates: ai`) — متى؟
- عندما يكون الموضوع بصرياً (أماكن، أحداث، أشياء) ويستحق لوحة كاملة بستايل Vox: فعّل `"plates": "ai"` واكتب `plate` بالإنجليزية لكل لقطة (بدون نص!). كل لوحة تتحرك بعمق (parallax) تلقائياً.
- الوثائقيات التاريخية: الأفضل صور أرشيفية حقيقية (`"image"`) + لوحات إجرائية.
- الميزانية المجانية لـ Gemini كافية لـ ~50 صورة/يوم: فيلم 3 دقايق كامل بلوحات ذكية + قصاصات ≈ 55 صورة → قسّمه على يومين أو استخدم اللوحات الإجرائية لنصف اللقطات (`"bg"` بدون `plate`).
