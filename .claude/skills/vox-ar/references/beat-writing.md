# Beat Writing — بنية القصة والإيقاع

## الأقواس السردية
| القوس | متى | التسلسل |
|---|---|---|
| `hook_payoff` | تعليمي عام (افتراضي) | خطّاف → سياق → بناء → المكافأة → خاتمة/CTA |
| `pas` | مشكلة يعاني منها الجمهور | مشكلة → تأزيم → حل → دليل → CTA |
| `myth_bust` | معلومة شائعة خاطئة | الخرافة (بختم "خطأ") → الحقيقة → لماذا → ماذا تفعل |
| `timeline` | تاريخ/رحلة | البداية → حدث 1 → حدث 2 → الذروة → الدرس |
| `how_it_works` | آلية/خطوات | خطّاف → نظرة عامة → خطوة خطوة → الفائدة → CTA |

## الإيقاع
- **الخطّاف ≤ 3 ثوانٍ:** "خبر عاجل" + سؤال مباشر أو رقم صادم. أول لقطة فيها عنوان أحمر + قصاصة واحدة + دائرة قلم.
- **ريل 30 ثانية:** 4 بيتات، 5–6 لقطات. **60 ثانية:** 6–7 بيتات، 10–12 لقطة. **فيديو طويل:** قسّمه لمقاطع 60 ثانية.
- **قطع كل 3.5–5 ثوانٍ.** بيت واحد = فكرة واحدة = جملة أو جملتان.
- **حدث بصري كل ~ثانية** داخل اللقطة (دخول طبقة، ختم، دائرة). اللقطة الفارغة من الأحداث لأكثر من 1.5 ث = مملة.
- **الكلمة المفتاحية = طبقة:** أهم كلمة في الجملة تظهر كعنوان مظلّل لحظة نطقها (`at` ≈ زمن الكلمة في التعليق).
- **الخاتمة:** CTA واضح بعنوان أحمر كبير (تابعني / احفظ الفيديو / شارك مع أم).

## التعليق الصوتي
- لهجة المستخدم (فلسطينية/شامية بيضاء): "ليش"، "بده"، "هيك"، "مش". جمل قصيرة، فعل في البداية.
- 2.5–3 كلمات/ثانية. بيت 4.5 ثانية ≈ 12–14 كلمة.
- علامات الترقيم تحدد تقطيع الكابشن: ضع فاصلة أو نقطة كل 3–5 كلمات.
- لا أرقام بالحروف الطويلة في الكابشن؛ اكتب "3 ساعات" لا "ثلاث ساعات".

## قالب ريل 30 ثانية (نيش تطوّر الطفل)
1. **خطّاف** — سؤال/خبر عاجل + صورة طفل أرشيفية + دائرة. (4.5 ث)
2. **الحقيقة/الدراسة** — ورقة بحث + ختم "دراسة" + عنوان الرقم. لقطتان. (8 ث)
3. **الحل العملي** — صورة أهل مع طفل + عنوان "الحل:" + سهم + ختم "مهم". (5 ث)
4. **CTA** — "تابعني" أحمر كبير + دائرة. (4 ث)
