# ליגת הניחושים · מונדיאל 2026 — אשכולות אורנים

תחרות ניחושים משרדית (mobile-first) למשחקי הנוקאאוט הנותרים של מונדיאל 2026, עבור ~400 עובדי בית האבות אשכולות אורנים בגדרה. כל עובד/ת מנחש/ת את תוצאת 90 הדקות (1 / X / 2) של כל משחק, ניחוש נכון = נקודה, והזוכה במקום הראשון מקבל/ת פרס של 200 ₪ בפודטראק.

A mobile-first workplace prediction league (~400 employees) for the remaining FIFA World Cup 2026 knockout matches — pick 1/X/2 per match, 1 point per correct call, ₪200 food-truck prize for first place.

## הרצה / Running

אפליקציית ווב סטטית — אין build ואין תלויות. פותחים את `index.html` בדפדפן, או מגישים את התיקייה מכל שרת סטטי (למשל GitHub Pages):

```bash
python3 -m http.server 8080
# → http://localhost:8080
```

## מסכים / Screens

1. **ניחושים (ברירת מחדל)** — שדה שם, כרטיס לכל משחק עם כפתורי 1/X/2, ספירה לאחור לנעילה (הופכת אדומה מתחת לשעה), כפתור שליחה דביק בתחתית, ושיתוף בוואטסאפ.
2. **דירוג** — טבלת הדירוג (זהב/כסף/ארד ל-3 הראשונים, סימון "אתה" לשורה שלך), כרטיס אלוף/ת בית האבות בסיום, ו"מי ניחש מה" — ניחושים נחשפים רק אחרי נעילת משחק (ירוק=נכון, אדום=טעות).
3. **העץ** — עץ הנוקאאוט (רבע → חצי → גמר) בגלילה אופקית; מנצחת מסומנת בזהב, וצ'יפ "אלופת העולם" מופיע בסיום.
4. **ניהול** — מוגן ב-PIN (ברירת מחדל `2026`, ב-`js/app.js → CONFIG`). המנהל מסמן תוצאות אמת; בתיקו בוחר מי העפילה. כל שינוי מעדכן מיד את הניקוד, הדירוג והעץ.

שלוש שפות מלאות (עברית / العربية / EN) עם היפוך כיוון אוטומטי; השפה נשמרת per-device.

## מבנה הקוד / Code structure

| קובץ | תפקיד |
|---|---|
| `index.html` | שלד האפליקציה + פונטים (Heebo/Rubik) |
| `css/style.css` | כל העיצוב (טוקנים: רקע `#14110F`, כרטיסים `#221D18`, זהב `#F2B32B`, אלמוג `#EF8E7D`, ירוק `#4E7E6B`) |
| `js/i18n.js` | טבלאות מחרוזות מלאות ל-3 שפות + תרגומי שמות קבוצות (מפתח קנוני: השם העברי) |
| `js/data.js` | מודל המשחקים, גרף ההזנה של העץ (`FEEDS`), זמני נעילה, ופתרון העץ (`resolveMatches`) |
| `js/store.js` | שכבת persistence (localStorage) — **הקובץ היחיד שצריך להחליף למעבר ל-backend משותף** |
| `js/app.js` | state, רינדור, אירועים, ספירות לאחור, שיתוף וואטסאפ, PIN |

## התקדמות העץ / Bracket auto-progression

מזהי משחקים: `r16a`, `r16b` (שמינית, נעולים) → `qf1`–`qf3` (רבע, קבוצות ידועות) → `qf4` = מנצחות שמיניות → `sf1`, `sf2` → `fin`. משחק שהקבוצות בו לא ידועות מוצג עם שמות placeholder ונעול; כששתי התוצאות המזינות קיימות, השמות והצבעים מתמלאים אוטומטית והמשחק נפתח לניחושים. משחק ננעל אוטומטית בזמן ה-`lockAt` שלו. **זמני חצאי הגמר והגמר הם הערכה — לאמת לפני עלייה לאוויר** (`js/data.js → LOCK_ATS`).

## ⚠️ דרישה קריטית לפרודקשן: backend משותף

הגרסה הזו שומרת הכל ב-`localStorage` **לכל מכשיר בנפרד** — כל טלפון רואה רק את המשתתפים שנרשמו בו. כדי שכל 400 העובדים יראו טבלה אחת חיה, יש להחליף את `js/store.js` ב-backend משותף (Firebase/Supabase עם realtime subscriptions, או Google Sheet + Apps Script). המודל:

- **Participants**: `{ id, name, picks: {matchId: '1'|'X'|'2'}, submittedAt }`
- **Results** (כתיבה למנהל בלבד): `{ matchId: '1'|'X'|'2' }` + `adv: {matchId: teamId}` (בתיקו — מי העפילה)
- **Config**: PIN של המנהל, טקסט הפרס, זמני נעילה (להשתמש בשעון שרת, לא בשעון הלקוח)

שדרוג אופציונלי: משיכת תוצאות אמת מ-API של תוצאות כדורגל (football-data.org / API-Football) עם מסך המנהל כ-fallback ידני.
